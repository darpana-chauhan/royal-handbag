# Royal Handbag

**PHP-MySQL Based E-commerce Project**  

This is a fully functional e-commerce website built with PHP and MySQL, hosted on InfinityFree.  
It includes user registration, product management, admin panel, shopping cart, and checkout functionality.  

---

## 🔗 Live Demo
Check the project live here: [Royal Handbag Live](https://royalhandbag.rf.gd/)

## 🔑 Admin Panel
Access the admin dashboard here: [Admin Login](https://royalhandbag.rf.gd/admin/login.php)  
> ⚠️ Use only authorized credentials to login. Admin panel allows product & order management.

## 💻 GitHub Repository
All project code is available here: [GitHub Repo](https://github.com/darpana-chauhan/royal-handbag)

---

## ✨ Features

- User Registration & Login
- Admin Panel for Product & Order Management
- Add, Edit, Delete Products
- Shopping Cart Functionality
- Checkout & Payment Simulation
- Responsive Design (Mobile & Desktop)
- Secure Password Hashing (bcrypt)
- Separate User & Admin Authentication
